# ML Model Evaluation Workflow with Outputs

## Description

This project demonstrates a complete machine learning model evaluation workflow using a synthetic placement dataset.

## Workflow

- Exploratory Data Analysis
- Data preprocessing
- Feature engineering
- Train/validation/test split
- Cross-validation
- Classification models
- Regression models
- ROC and Precision-Recall curves
- Model calibration
- Hyperparameter tuning
- Grid Search
- Randomized Search
- Bayesian optimization
- Learning curves
- Validation curves
- Statistical significance testing
- Final model comparison

## Dataset

A synthetic placement dataset is generated using:

`data/create_dataset.py`

The generated dataset contains student academic, attendance, internship, project, test-score and placement information.

## Models

### Classification
- Dummy Classifier
- Logistic Regression
- Random Forest Classifier

### Regression
- Linear Regression
- Random Forest Regressor
- Dummy Regressor
